MinMax Scaling

Linearly transforms feature coordinates to a fixed range, usually [0, 1]. Preserves zero values for sparse data but is highly sensitive to outlier values.

xscaled = (x - xmin) / (xmax - xmin)

Z-Score Standardization

Rescales coordinates around a mean (μ) of 0 with standard deviation (σ) of 1. Standardizes metrics across features with varying units or magnitudes.

z = (x - μ) / σ
